## News

### Mobile Releases are under review!
Mobile versions are finally ready and its so much smoother than using a browser!

The app must be reviewed by Google and Apple before it will be accessible publicly, but I can give anyone early access by adding them to my internal testing program. This gives you access to the latest versions before they become public, use the app as you usually would, and report any suggestions or bugs that you notice.

I'll be grateful for anyone who wants to join early access! If you join, there
is no obligation to report anything, you mostly just get to use the latest
version before everyone else! Sign up for early access by emailing me whether
you are on iOS or Android and the email address associated to your google or
apple account!

## Additions to the App
### New Features
- Safari support - Mac users should now be able to launch the app in Safari!
- Style overhaul
- Profiles now show approximate distance ("X miles away")
- Notification icons when there is a new message or like.
- Email verification

### Invisible Improvements
- Android native photo selection
- API versioning
- Search improvements
- API refactoring to make it more robust
